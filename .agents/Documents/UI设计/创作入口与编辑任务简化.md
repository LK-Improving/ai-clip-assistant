# 创作入口与编辑任务简化

版本：2026-10-04。依据：用户本轮确认的四项调整，以及本轮视频对照分析 `C:/Users/LK/.codex/visualizations/2026/10/04/01a106c7-ba05-7330-917b-682b974acbeb/video-comparison/对照分析.md`。

## 页面与交互

- 默认入口为 `/new`；旧 `/launch`、`/home` 兼容跳转至 `/new`。统一从创作页输入需求或创建空白项目，生成及分镜确认仍由 `/chat` 承接。原启动页和工作台源码保留，但不再注册独立页面入口。
- 外壳移除重复的新建按钮与工作台入口，创作对话保留在辅助导航中。创作页移除右侧宣传区，改为居中单列表单。
- 每次进入编辑器，导航默认收起为 68px 图标栏，可手动展开；编辑器隐藏全局用户顶栏。离开编辑器恢复普通页面布局。
- 右侧设置按画面、口播、字幕、音乐四个任务切换，支持方向键及 Home/End。选中时间线片段自动切换到对应任务；每个任务只允许调整匹配类型的选中片段，也能从下拉框选择该任务的片段。
- 时间与裁剪、转场/淡入淡出默认折叠。画面保留变换与原声音量；字幕保留文本和样式；口播保留配音生成和音频控制；音乐展示素材库音频，可添加到音乐轨并调整音量。
- 音乐轨沿用现有名称约定：名称含“音乐/配乐/music/bgm”的音频轨归音乐任务，其余音频轨归口播。没有新增工程字段；已有自定义轨道名称可能需要按此约定命名。
- 添加音乐与配音时使用最新时间线状态；音乐默认音量 25%，无音乐轨时创建“音乐”轨，无口播轨时配音创建“旁白”轨。通过原有 action/store 保存和撤销。
- AI 助手入口放在编辑器工具栏；关闭时不再显示遮挡属性值的右缘把手。

## 边界与状态

输入：已有需求、素材、时间线轨道与片段、当前选中项、配音文本。

输出：导航/任务显示状态，以及通过既有 action 通道写回的片段属性、音乐与配音片段。

错误/降级：沿用既有创作、配音、工程保存提示；浏览器无 Electron 桥时不会调用系统或 Provider。本轮验证了配音的浏览器不可用提示。浏览器示例素材修改后显示保存失败，因为预览没有桌面保存桥。

取消：保留原有生成停止、分镜取消、任务失败重试路径；任务标签切换和收起助手不会取消正在运行的任务。

本轮不修改 IPC、外部 Provider、核心 DSL 或 FFmpeg 契约。未改造独立导出页及创作高级参数。
