## 一、项目定位

企业级**类剪映视频智能剪辑工具**——一款面向音视频剪辑场景的垂类 **AI Agent 桌面应用**。用户用自然语言描述创意，Agent 自动完成从创意简报 → 分镜规划 → 素材匹配 → 语音合成 → 时间线组装的全链路，并支持人机协同（分镜可编辑后继续生成）。所有素材与创作过程均在本地完成，满足隐私合规。

**目标用户分层**：内容创作者（短视频 / 知识付费）、企业营销人员（产品宣传 / 培训视频）、普通个人（旅行记录 / 家庭相册）。

## 二、核心功能

- **自然语言驱动**：输入需求 + 选择素材目录，自动产出可剪辑工程。
- **本地素材管理**：`ffprobe` 元数据提取、关键帧缩略图、**增量扫描**（对比 size / mtime）、手动导入保留（`imported` 标记）；**语义预处理（P2）**：扫描即产出启发式描述 + 96 维本地确定性特征向量（中文 bigram + 哈希词袋 + L2 归一化），支持**语义搜索**（离线可用，无需向量数据库/大模型）。
- **可视化编辑器**：经典五区布局（顶部工具栏 / 左侧素材·分镜 / 中间预览 / 右侧属性 / 底部时间线），轨道拖拽、缩放、预览联动；属性面板支持片段**淡入/淡出转场**（视频/图片写为 fade 转场，音频写为音量淡变）。
- **项目管理**：工程卡片网格 + 搜索 + 排序（时间/名称）+ 批量删除 + 空态/失败状态处理。
- **AI 视频生成** ⚠️：缺素材场景由 **MiniMax H3（Hailuo 3.0）文生视频**补帧（`generate-clips` 节点），非火山视频生成。
- **TTS 旁白**：火山引擎 **WebSocket 流式**合成 + 本地 Provider（`baseUrl` 适配）+ **零样本声音克隆**（M3：自托管服务协议对接 + 音色库全链路管控 + 双路由降级）+ **离线静音兜底**。
- **FFmpeg 渲染**：时间线 JSON → `filter_complex` → MP4，多轨视频叠加、音频混音、字幕烧录（drawtext）；片段 `effects` 消费（fade-in/fade-out 转场、eq/blackwhite/blur 滤镜白名单，未知效果降级告警）；失败/取消自动回滚半成品产物；跨平台路径 / 字体兼容。
- **本地协议预览**：`miaoma://` 私有协议 + **Range 请求**，解决 `file://` 跨域与进度拖动，含路径白名单安全机制。

## 四、技术选型（准确版）

- **包管理**：pnpm workspace（monorepo）。
- **桌面**：Electron **44** + Electron Forge 7 + Vite 7。⚠️（原 PDF 写 Electron 38）
- **前端**：React 19 + TypeScript 5 + TailwindCSS 4 + shadcn/ui。
- **智能体编排**：**LangGraph.js（@langchain/langgraph ^1.4）**——StateGraph + 原生 `interrupt()` 人机中断 + Checkpoint 机制；`JsonFileCheckpointSaver`（继 MemorySaver 落盘 JSON）实现崩溃后断点续跑。
- **AI 基础层**：**LangChain.js（@langchain/core ^1.2）**提供模型抽象与 Prompt 模板；本地模型经 **@langchain/ollama**（ChatOllama），火山方舟经 **@langchain/openai**（ChatOpenAI 兼容端点）。
- **LLM / TTS 接入**：LLM 经 LangChain `BaseChatModel` 抽象（离线确定性 / 火山方舟 / 本地 Ollama）注入；TTS 经 Provider 适配器（火山/本地/离线），支持无缝切换与故障降级。
- **数据模型**：`@miaoma/video-project`，Zod 4 判别联合（判别字段 `type`），`schemaVersion` 迁移。
- **结构化输出**：**Function Calling + Zod 运行时校验 + 失败自动重试（带错误回灌）+ 降级兜底**（`invokeStructured`：支持工具的模型走 `bindTools` 原生工具调用，离线/不支持工具的模型走 JSON 内容解析，同一校验/重试链兜住）。
- **存储** ⚠️：工程与素材索引均为**本地 JSON**（工程 JSON + `library-cache.json`，含语义特征向量），**无 SQLite**。（原 PDF 写"素材索引: SQLite"）
- **视频生成**：MiniMax H3（Hailuo 3.0）v2 API（建任务 → 轮询 → 下载）。
- **实时进度**：渲染进程经 **IPC 事件广播**（`agent:event`，带自增 `seq` 序号防丢，断档自动用 status 快照补偿对齐）推送节点进度；**M2 已实现 token 级 LLM 流式**（`model.stream()` + 离线分块模拟，`type:'token'` 事件驱动 UI 打字机，AbortSignal 全链路取消）。⚠️（传输层是 IPC 事件流而非 HTTP SSE——桌面应用无服务端，能力等效）

## 五、智能体引擎（@miaoma/agent）

**10 节点流水线**（LangGraph StateGraph 真实节点，2026-09-18 升级）：

```
scan-assets → creative-brief → storyboard-plan → storyboard-review(interrupt)
            → match-assets → generate-clips(MiniMax H3 文生视频) → speech-synthesis
            → assemble-timeline → validate(Zod) → save-project
```

（节点名 `storyboard-plan`：LangGraph 要求节点名不与状态通道 `storyboard` 同名）

- **人机中断**：storyboard-review 节点调用 LangGraph 原生 `interrupt()` 暂停；外部编辑分镜后经 `Command({ resume: scenes })` 续跑后半段。
- **失败断点重试**：桌面端每次运行写 `userData/agent-runs` checkpoint，失败/崩溃后可经 `agent:retry` 以原生 LangGraph 语义从断点继续执行到完成（AI 工作台/分镜页提供「断点重试」入口），成功后自动清理。
- **Checkpoint 断点续传**：LangGraph Checkpoint 经 `JsonFileCheckpointSaver` 每步落盘 `langgraph-checkpoint.json`，崩溃后 `resumeFromCheckpoint` 以原生 LangGraph 语义从中断点恢复（含 pending interrupt）。
- **离线兜底**：无密钥 / 无网络时走 Offline ChatModel / TTS / VideoGen Provider，整条链路仍可端到端跑通。
- **事件上报**：带进度的节点广播 + **token 级 LLM 流式（M2）**——creative-brief/storyboard-plan 的结构化生成经 `model.stream()` 逐块推送（离线模型 12 字符分块同构模拟），UI 打字机展示，signal abort 即时停流。
- **语义素材匹配（P2）**：match-assets 节点用 `embedText(场景文本)` 与素材 embedding 的余弦得分做全局贪心分配（每素材至多用一次）；无中文/名称信号时得分全 0，退化为原类型轮转，保证确定性（离线冒烟实证）。

## 六、数据模型 DSL（@miaoma/video-project）

- **判别联合类型** ⚠️：`VideoClip` / `ImageClip` / `AudioClip` / `TextClip`（字幕），判别字段 **`type`**。（原 PDF 写 `kind` 字段 + `VideoClip/VoiceClip/SubtitleClip/MusicClip`）
- `Asset`（磁盘素材）与 `Clip`（时间线一次摆放）分离；一个素材可被多片段引用。
- `Track` 分层（视频 / 音频 / 字幕）。
- `schemaVersion`（**number** 类型）⚠️ + `migrate` 迁移；`loadProject()` 先迁移后 Zod 校验。
- 跨字段校验：资产存在性、时间合法性、轨道类型匹配。

## 七、素材管理 / TTS / 渲染 / 桌面端

- **素材管理**：`ffprobe` 元数据 + 关键帧缩略图 + `library-cache.json` 增量缓存；损坏 / 格式不兼容文件单独跳过不中断；**语义预处理已实现（P2）**：描述 + 特征向量随扫描写入缓存，`library:search` 语义检索（余弦 + 关键词加成）；**M4 多模态增强**：扫描时对关键帧计算 CLIP 视觉向量（512 维，仅存库缓存不进工程 JSON，检索双空间 max 融合），可选方舟视觉模型生成真实画面描述替换启发式摘要；视觉链路**全链路可降级**（模型未下载/依赖缺失/推理失败 → 静回退词法向量，扫描与检索绝不触发意外下载）。⚠️（真 CLIP 运行需 Node ≥20.19（项目 engines 要求）+ `pnpm vision:warmup` 预下载；降级与维度保护已有冒烟实证）
- **AI 智能转场（M4）**：assemble-timeline 按确定性节奏规则自动注入转场——首段淡入 800ms、末段淡出 1200ms、连续快切换场（任一段 <4s）成对 400ms 淡出/淡入；幂等可重跑、不覆盖用户已设转场（引擎冒烟⑦环 + filter_complex 链路断言实证）。
- **TTS**：火山引擎 WebSocket 流式合成；本地 Provider 为 `baseUrl` 通用适配；**零样本声音克隆（M3）已实现**：音色库导入参考音频（ffprobe 时长 3–20s + ffmpeg volumedetect 非静音校验）→ `POST {baseUrl}/tts/zero-shot` 克隆协议（对接自托管 Index-TTS 2 类服务，**服务需用户自备，未内置模型权重**）；在线/本地双路由降级链（零样本失败静回退火山→离线静音）；音色索引 `voices.json` 原子写，试听走 `miaoma://`，删除连带样本清理；分镜页每场可选克隆音色（`scene.voiceId` 经流水线透传）；LRU / 内容哈希缓存避免重复请求。⚠️（“内置 Index-TTS 2 模型权重”仍未提供，属体积决策）
- **渲染**：时间线 JSON → `filter_complex`；多轨叠加、混音、字幕烧录；`effects` 转场/滤镜白名单消费（未知项降级告警，不把工程 JSON 当作注入面）；H.264（CRF / preset）调优；`stderr` 进度解析 + `AbortController` 全链路取消 + 失败产物回滚删除。
- **桌面端**：三层进程（主进程 / 预加载 / 渲染）；IPC `invoke/handle` + `send/on`；`miaoma://` 私有协议 + Range；`extraResources` 含完整 ffmpeg；跨平台打包（Windows nsis / macOS dmg+条件公证 osxNotarize / Linux deb+rpm 配置就绪）；导出前 `fs.statfs` 磁盘空间预检（不可用时安全跳过）+ 失败错误五类中文分类（P3）；**工程版本管理 + 云端协同（M5）**：保存自动 git 快照（isomorphic-git，`userData/project-repo`），历史列表/字段级 diff/一键回滚（回滚作为新版本、历史线性不重写），可选 GitHub/Gitee 远端 https+token 手动 push/pull（离线本地历史完整可用，token 仅存本机）；仓库损坏自愈重建，快照失败不阻断保存。

## 九、简历安全表述（对外口径）

**一句话**：独立开发企业级 AI 智能剪辑桌面应用，基于 LangGraph.js（@langchain/langgraph）StateGraph 编排 10 节点剪辑流水线，经 LangChain.js 集成火山方舟 LLM、火山 TTS、本地 Ollama 与 MiniMax H3 视频生成，支持人机协同与本地隐私兜底，全链路端到端跑通。

**可写**：Electron + React 19 桌面端；LangGraph.js StateGraph + 原生 interrupt 人机中断 + Checkpoint 断点续传（JSON 文件持久化，失败断点重试）；LangChain.js 模型抽象 + Function Calling + Zod 校验 + 失败自动重试；LLM token 级流式生成与 UI 打字机（IPC 事件流承载，等效 SSE 语义）；零样本声音克隆音色库；Zod 判别联合数据模型 DSL；Provider 适配器多供应商切换与故障降级；素材语义预处理与多模态检索（词法向量 + 可选 CLIP 视觉向量）；**工程 git 快照版本管理 + 可选远端协同（isomorphic-git，离线优先）**；带序号防丢的 IPC 事件上报；FFmpeg `filter_complex` 渲染 + `effects` 转场/滤镜消费 + 失败产物回滚；`miaoma://` 私有协议安全预览。

**谨慎写**（成立但有边界，被追问要能接住）：
- ⚠️ “零样本克隆”的实现形态是**协议适配自托管服务**（需用户自行部署 Index-TTS 2 等 zero-shot TTS，未内置权重）——应表述为“设计了音色导入校验与零样本合成的全链路管控，对接本地自托管克隆服务”，不可说“模型内置在应用里”
- ⚠️ “多模态素材理解”已落地为 CLIP 视觉向量检索（transformers.js + q8 量化模型，首用需 Node ≥20.19 + warmup 下载）；视频是**关键帧代表理解**，非逐帧/音视频全模态，表述用“基于关键帧的多模态语义检索”
- ⚠️ “云端协同”的实现形态是 **git 引擎对接用户自备的 GitHub/Gitee 私有仓**（https+token 手动 push/pull），无自建后端服务；真实 push/pull 未在联网环境实测（错误语义与本地历史已冒烟实证）

**实测数据（M6，`pnpm bench:metrics` 可复跑，详见 `docs/性能与效果实测.md`）**：
- 增量重扫 20 文件 **20ms vs 全量 21.4s（≈1068x）**——对应 PDF「分钟级→秒级」可升级为实测量级；
- TTS 重复请求内存 LRU 命中 **1ms vs 未命中 1.5s（含 200ms 网络 RTT）**——对应 PDF「10 倍以上」有实测支撑；

- LangGraph 崩溃恢复（checkpoint 续跑后半程至出工程）**275ms**；110 片段工程保存 21ms / 读取 40ms。
