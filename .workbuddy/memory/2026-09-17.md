## 当前项目 vs 项目介绍 PDF（watermarked）差异核对

对照 PDF（19 页项目介绍/架构文档）与实际代码，结论：功能链路（导入→AI→剪辑→导出）已全跑通、冒烟全绿，但与 PDF 这份对外介绍存在多处显著差异，多为「文档把计划/理想架构写成已实现」。

关键差异（已用代码核实）：
- **未真用 LangGraph.js / LangChain.js**：`@miaoma/agent` 仅依赖 `@miaoma/video-project`，流水线为手写 `execute()` 循环 + 手动 checkpoint JSON（README 自述为「LangGraph 式编排」）。PDF 把 LangGraph.js + @langchain/core + @langchain/ollama 列为智能体核心栈，且标题含 Langchainjs —— 均不实。
- **包名不符**：PDF 称 `@miaoma/video-agent`；实际为 `@miaoma/agent`。
- **节点数**：PDF 说 10 节点；实际 PIPELINE_NODES 注册 7 个（scan-assets / creative-brief / storyboard / match-assets / generate-clips(新增, MiniMax H3) / speech-synthesis / assemble-timeline）。缺失「素材分析/语义预处理」独立节点；分镜审批=中断暂停点（非节点）、验证=内联 Zod.parse、保存=桌面端侧。实施计划.md 原定 6 节点。
- **数据模型 DSL**：判别字段实际 `type`（PDF 写 `kind`）；片段类型实际 VideoClip/ImageClip/AudioClip/TextClip（PDF 写 VideoClip/VoiceClip/SubtitleClip/MusicClip）；schemaVersion 为 number（PDF 写 '1.0.0' 字符串）。
- **本地 TTS / 音色克隆缺口**：`tts/providers/local.ts` 只是 POST `{baseUrl}/tts` 的通用适配，未内置/集成真实 Index-TTS 2；「自定义音色库 / 声音克隆 / 零样本克隆」全代码无实现（grep 无 clone/克隆/音色库）。
- **素材索引存储**：PDF 指定 SQLite；实际 `library-cache.json`（自定义 JSON LibraryStore），无 SQLite/lowdb。
- **轻微项**：Electron 38(PDF)→44(实际)；PDF 标题误写 Vue3（正文 React19，实际 React19 正确）；SSE(PDF)→IPC 事件广播(实际)；Husky/Commitlint、Zustand、XYFlow 多为「可选」未采用。

面试/简历风险：对外文档与代码不符，建议要么改 PDF 措辞对齐代码，要么补真实 LangGraph/Index-TTS2/声音克隆。
